# Hardinge Road L19 — Correct Image Update

This package contains the complete website with the exact property photographs, floor plan, Street View image, nearby-schools map, market comparison images and road-view video supplied in the conversation.

## Upload to GitHub

1. Extract this ZIP.
2. Open the extracted folder.
3. Select every file and folder inside it.
4. Drag them into the GitHub upload page for `hardinge-road-l19/hardinge-road-l19`.
5. GitHub will ask whether to replace files with the same names; keep the new files.
6. Commit with: `Add all correct property and local-area images`.
7. Wait for GitHub Pages to redeploy, then hard refresh with Ctrl + Shift + R.

Do not upload the ZIP itself. The `assets` folder and `index.html` must remain at the repository root.

The GitHub account/settings screenshots are deliberately excluded from the live website imagery.
