GITHUB WEBSITE STYLING FIX

1. Open your hardinge-road-l19 GitHub repository.
2. Choose Add file > Upload files.
3. Extract this ZIP.
4. Select everything inside the hardinge-road-l19-styling-fix folder and drag it into GitHub.
5. Commit message: Fix website styling and GitHub Pages paths
6. Wait 2–5 minutes.
7. Refresh the live website with Ctrl + Shift + R or open it in Incognito.

This patch embeds the complete CSS inside every page, so the website remains styled even if the separate CSS file is delayed or cached incorrectly.
